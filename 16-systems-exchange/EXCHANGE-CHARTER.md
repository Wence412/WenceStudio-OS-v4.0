# WenceStudio Systems Exchange Charter

## Purpose

WenceStudio Systems Exchange is the governed access layer for reusable WenceStudio agents, workflows, prompt systems, skills, SOPs, and implementation kits. It helps users discover approved systems while preserving WenceStudio OS v4.0 controls.

## Scope

The Exchange may catalog:
- Agents
- Workflows
- Prompt systems
- Skills
- SOPs
- Implementation kits
- Learning paths

The Exchange is not an autonomous publishing, outreach, payment, credential-management, or production-change system.

## Operating model

1. A system record is drafted in the Master Registry.
2. The owner validates purpose, boundaries, dependencies, and evidence.
3. A governance review assigns a risk tier and human approval points.
4. An approved system may be listed in the Exchange.
5. Changes, failures, and deprecations update the canonical record first.

## Listing rule

The Master Registry is authoritative. The Exchange is a curated view and must never create a competing source of truth.
