# System Records

Each file in this directory is the private operating specification for one Systems Exchange listing.

## Status conventions

- `implementation_status: specification_only` means the file defines the intended control model. It does not claim that a runnable agent or automated workflow has been built.
- `listing_status` governs the Exchange catalog state. It does not grant access, permissions, or authority to operate.
- A named owner must replace the placeholder reviewer and confirm validation evidence before any release-state change.

## Record requirements

Every record identifies approved inputs and outputs, data classification, risk tier, prohibited uses, human approval points, validation criteria, and release conditions.
